# Maylix
A rule based chatbot built with Python and NLP techniques. Maylix matches
your input to predefined patterns and replies with the best matching response.

## How to run
pip install nltk numpy
<br>
python chatbot.py

## Features

1. Natural Language Processing (tokenizing, lemmatizing)
2. Cosine similarity matching
3. Fully offline — no internet required
4. Customizable via JSON dataset
5. Lightweight and easy to run

## How It Works

1. User types a message
2. Message is tokenized and lemmatized
3. Converted into a Bag of Words vector
4. Compared to all patterns using Cosine Similarity
5. Best matching intent is selected
6. A random response is returned
